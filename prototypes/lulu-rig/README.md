# 张噜噜 3D 骨骼原型 01

本地角色原型，未替换 WPF 桌面角色，也未实现睡铺流程。用户在 2026-11-11 明确选择先看可控的 3D 骨骼角色。

## 打开

在此目录执行 `node server.mjs`，浏览器打开 `http://127.0.0.1:8426/`。`start.ps1` 可启动隐藏的本地服务并打开浏览器。服务只绑定本机回环地址，无云端上传、密钥或付费 API。

- 拖动旋转，滚轮缩放；正面、侧面、背面和恢复视角均可用。
- 开始走路 / 慢慢停下：逐步加减速，完成当前摆腿后依次收脚。
- 暂停 / 继续；0.5～1.4 倍步速。
- 查看骨骼、脚掌落点；检查实际蒙皮脚掌的滑移、穿地和间隙。
- 导出 `zhang-lulu-rig-prototype.glb`：真实三维网格、18 根骨骼、蒙皮与 6 秒 `Walk_then_settle` 动画。该动画是走路后停步的单次动作，不是循环片段。

## 实现与验证

`rig.mjs` 建立圆润的实体头、口鼻、眼镜、头发、躯干和四肢，使用 Three.js `SkinnedMesh` 绑定骨骼。`locomotion.mjs` 保存世界坐标中的脚掌落点；支撑脚保持固定，摆动脚沿连续曲线抬起前移。髋膝踝通过双骨 IK 跟随目标，动画按时间更新，不切换视频帧。

`node locomotion.test.mjs` 验证 24 秒的行走、加速、停步与再启动：45 次落脚，落地目标滑移为 0，最大逐帧脚掌位移 0.02526 模型单位，腿部最大目标距离 0.42395（两节骨长合计 0.44）。浏览器内检查另测实际蒙皮顶点和脚踝世界位置，不只测控制目标。

已验证 GLB 2.0 文件长度、13 个网格和蒙皮、18 个关节、57 条动画通道。依赖固定为 Three.js 0.180.0，选用模块保存在 `vendor/`，MIT 许可证位于 `vendor/LICENSE`。

## 当前限制

这是程序建模的首版原型，视觉精细度尚不等于已批准的毛绒参考图。毛发、手脚、裤装与软组织仍需雕刻和材质细化。没有盖被、入睡、唤醒、表情系统或桌面集成；形象和基础步态确认后再扩展，避免把未确认模型批量制作成全部动作。
