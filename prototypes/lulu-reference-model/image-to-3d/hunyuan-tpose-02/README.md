## 骨骼与修整

官方 Make-It-Animatable v2：Input Rest Pose=T-pose，No Fingers=true，Restore Global Transform=true，清空外部动画。

生成了 22 根骨骼：脊柱、颈、头、双肩、上臂、前臂、手腕、双侧大腿、小腿、脚和脚趾根。使用 Mixamo 命名，便于后续动作重定向；没有独立手指、面部表情骨骼或 shape keys。小尾巴当前跟随骨盆，没有独立尾巴控制器。

在自动结果上做了这些修整：

1. 统一骨骼到角色的世界坐标，并把导入 GLB 的短骨尾恢复成可编辑的关节链长度。
2. 平均左右对应关节的位置，修正自动检测中不一致的膝关节高度。
3. 对颈部以下的蒙皮权重做 36 次网格邻接平滑并归一化。没有平滑角色网格来抹掉脸部形体。
4. Blender 文件启用保体积蒙皮及 12 次关节表面修正，减少大角度弯肘、抬腿时的局部凹陷。
