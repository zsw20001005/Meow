# 噜噜五组骨骼动作试作

从上一轮 `rigged/Lulu-Tpose-Rig-Preview.blend` 继续制作，没有修改角色参考图、重新生成形体或替换桌宠应用素材。

查看 `lulu-five-motions.mp4`，五段依次为：待机呼吸、左右张望、挥手、起步行走停下、踏步转身一圈。每段也分别保存为 `lulu-idle.mp4`、`lulu-look.mp4`、`lulu-wave.mp4`、`lulu-walk.mp4`、`lulu-turn.mp4`。全部 640×640、30 fps，灰模真实渲染。

`Lulu-Five-Motions.blend` 包含五个独立 Action；`Lulu-Five-Motions-Preview.blend` 另外包含预览相机和静止地面参照网格。使用 Blender Action Editor 切换 `Lulu_Idle`、`Lulu_LookAround`、`Lulu_Wave`、`Lulu_WalkSteps`、`Lulu_StepTurn360`。各动作帧数和检查值见 `manifest.json`。

## 本轮内容

- 呼吸：胸腹小幅起伏、手臂轻微跟随，4 秒循环。
- 张望：颈部与头部分摊转角，左右查看后回到中立姿态，4.8 秒。
- 挥手：先抬臂弯肘，再摆手，最后放回原位，4.8 秒。
- 行走：双腿交替支撑，抬脚后前迈，角色实际向前移动 0.72 个模型单位，最后收脚停下，约 4.27 秒。这是带起止的行走片段，不是无限步行循环。
- 转圈：角色本体绕竖直轴转 360°，每次约 30°、双脚交替迈步，最后收脚。镜头方向固定，约 6.2 秒。

五段采用统一中立站姿作为起止。行走终点相对场景有位移，接入应用时应正确保留根运动，不能每次把它瞬间归零。

## 检查和修整

1. 使用解析两段腿部 IK，让支撑脚的踝关节在落地期间固定于世界空间。计算和已烘焙动作的抽样播放检查误差均小于 0.000001 模型单位。它验证的是关节目标，不等于所有脚底网格顶点都绝对不动。
2. 首版转圈 45° 跨步使短腿和裤腿扭转明显，改为 30° 步进，增加末尾收脚。
3. 身体移动/转动使用单调 Hermite 插值，避免结束时过冲再倒回；抬脚用平滑起落曲线。
4. 每段至少检查了七个时间点的实际模型渲染；预览固定相机方向。行走相机只跟随平移，地面网格始终静止。
5. 源网格、22 根骨骼、保体积蒙皮和关节平滑修正均沿用上一轮。没有独立表情、眨眼或嘴部动作。
6. `playback-check.json` 对已保存文件重新加载检查：五段起始网格姿态一致；消除行走的整体平移后，各片段结束与开始的最大顶点差小于 0.000001 模型单位。抽样网格均为有限坐标，脚底最低处约为 -0.00112；预览地面位于 -0.035，未发生地面裁切。这不是全动作自碰撞证明。

## 仍需完善

这是身体动作原型。短腿在迈步、转身时，裤腿与裆部仍可能有局部压缩和轻微褶皱；还需按用户反馈调整步幅、节奏和蒙皮。头部没有眼球注视或面部表情，所以目前不会呈现完整的情绪表演。视频展示的是 Blender 修正后的效果，不能当作标准 GLB 实时播放已等价验证。
