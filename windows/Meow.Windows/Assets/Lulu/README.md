# 张噜噜角色素材

以用户选择的第一版 Product Design 图为视觉依据，由 Image Gen 生成透明毛绒角色。`reference.png` 保存所选原图，运行时角色不使用原图背景。

- `idle.png`: 站立主形象。
- `motion.png`: 4×4，按行分别为旧走路、旧挥手、睡觉、思考；前两行保留作为生成来源，运行时改用新动作图。
- `interactions.png`: 4×4，按行吃西瓜、旧玩球、抱信、说话；玩球改用新动作图。
- `walk.png` / `wave.png` / `play.png`: 每图4×4、按行排列的16张连续动作关键帧。
- `expressions-a.png`: 4×4，按行开心、喜欢、生气、委屈。
- `expressions-b.png`: 4×4，按行害羞、惊讶、困倦、饥饿。
- `reactions.png`: 4×4，按行好奇、晕乎乎、伸懒腰、跳舞。

切格使用按实际尺寸计算的整数比例边界，不假设图片宽高能被4整除。每行统一alpha主体边界；16帧动作统一整张图主体边界。逐帧独立裁紧会造成角色位置、大小跳动，因此禁止。预乘alpha通道插值保证桌面背景不会透过不透明身体；有界缓存防止长时间播放持续增加内存。
