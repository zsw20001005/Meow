Meow · 张噜噜 Windows 精简体验版

适用于 Windows 10（2004 或更新版本）/ Windows 11，64 位系统。
包含 .NET 运行环境、当前全部角色动画、云端 API 聊天与信箱通信组件。
此安装包不包含本地模型权重和 llama.cpp 本地推理引擎。

安装前，请从噜噜的右键菜单退出正在运行的旧版。
默认安装到当前用户的 LocalAppData\Programs\Meow。
如果电脑缺少 Visual C++ 运行库，安装程序会调用随附的微软官方安装程序，届时需要管理员授权。

安装后双击桌面“Meow · 张噜噜”启动。拖到屏幕边缘可进入扶边状态；右键打开设置、动作和表情菜单，双击角色打开对话。
在设置中选择云端模型服务商，填写模型名称和你自己的 API Key。
如之前启用了本地模式，请改选云端模型；此版本不能启动随附本地模型。

你的设置、聊天记录和信箱身份保存在 %LOCALAPPDATA%\Meow.Windows。
升级与卸载保留存档。覆盖完整版不会自动删除先前安装的模型；如需腾出模型占用空间，可先卸载完整版，再安装精简版。
本安装包不包含发布者的 API Key、聊天记录或信箱私钥。

本体验版尚未配置代码签名证书。
