Meow · 张噜噜 Windows 体验版

适用于 Windows 10（2004 或更新版本）/ Windows 11，64 位系统。
已包含 .NET 运行环境、当前全部角色动画、信箱通信组件。
完整安装还包含轻量本地模型；只用云端 API 时可选择精简安装。

安装前，请从噜噜的右键菜单退出正在运行的旧版。
默认安装到当前用户的 LocalAppData\Programs\Meow。
如果电脑缺少 Visual C++ 运行库，安装程序会调用随附的微软官方安装程序，届时需要管理员授权。

安装后双击桌面“Meow · 张噜噜”启动。拖动到屏幕边缘可进入扶边状态；右键打开设置、动作和表情菜单，双击角色打开对话。
云端聊天需要在设置中填写你自己的模型服务商、模型名称和 API Key。
轻量本地模型适合简单对话，效果与大型云端模型不同。

你的设置、聊天记录和信箱身份保存在 %LOCALAPPDATA%\Meow.Windows。
更新会继续使用原存档；卸载保留存档。本安装包不包含发布者的 API Key、聊天记录或信箱私钥。

本体验版尚未配置代码签名证书。
